## Сборка и Java-тесты

Из корня проекта, для frontend:

```sh
cd frontend
npm ci
npm run check
npm run build
npm run build:api
```

В отдельном терминале из корня проекта:

```sh
cd backend
mvn test
```

Java-тесты проверяют создание и чтение инициатив, сочетание фильтров, некорректные поля и даты, повторные имена участников, закрытые и заполненные инициативы, статистику и CORS. Отдельный тест одновременно отправляет записи на участие и проверяет, что число участников не превышает вместимость. Публичные ответы проверяются без раскрытия имён волонтёров.

## Браузерные тесты

Для свежего клона выполните из `frontend/`:

```sh
npm ci
npx playwright install chromium
npm run test:e2e
```

Конфигурация Playwright запускает `npm start` на порту 4200 и использует отдельные браузерные контексты. Если на этом порту уже работает dev server, локальный запуск использует его. Для автономных тестов нужен именно режим `npm start` с демоданными, а не автоматически подключённый API-режим.

В текущей Windows-среде тесты запускались через установленный Chrome:

```powershell
$env:PLAYWRIGHT_CHANNEL = "chrome"
npm run test:e2e
```

Без этой переменной Playwright использует установленный им Chromium. Одиннадцать основных сценариев покрывают карту и выбор города, SVG-режим без WebGL и клавиатуру, сочетание фильтров, избранное, участие, создание инициативы, переключение RU/KK, фокус и Escape в диалоге, мобильное меню и отсутствие горизонтального переполнения на ширине 375 px.

### Дополнительный сценарий Angular → Java → база

Запустите Java API на порту 8080. На порту 4200 должен быть доступен Angular с proxy `/api` на Java; обычный `npm start` уже содержит эту настройку. Playwright может запустить этот dev server самостоятельно, если порт свободен.

Из `frontend/`:

```powershell
$env:PLAYWRIGHT_CHANNEL = "chrome"
$env:QAMQOR_TEST_API = "1"
npm run test:e2e
Remove-Item Env:QAMQOR_TEST_API
```

Так запускаются все 10 сценариев. Чтобы выполнить только API-сценарий:

```powershell
$env:QAMQOR_TEST_API = "1"
npm run test:e2e -- e2e/api.spec.ts
Remove-Item Env:QAMQOR_TEST_API
```

API-тест подключается к серверу, создаёт вымышленную инициативу, записывает вымышленного участника, проверяет сохранённый результат через REST и отказ при превышении вместимости. **Тестовая запись остаётся в используемой серверной базе.** Для повторяемой демонстрации запускайте его с локальной учебной базой.

## Скриншоты и графика

Файлы включены в репозиторий:

- [`dashboard.png`](images/dashboard.png) — desktop, viewport 1536 × 1480, снимок видимой области.
- [`mobile.png`](images/mobile.png) — mobile, viewport 390 × 844, снимок всей страницы.

Для повторного создания запустите приложение на `http://127.0.0.1:4200`, затем из `frontend/`:

```powershell
$env:PLAYWRIGHT_CHANNEL = "chrome"
npm run screenshot
```

Скрипт по умолчанию использует установленный Chrome. Переменная `PLAYWRIGHT_CHANNEL` выбирает другой установленный канал Chromium-браузера; `QAMQOR_URL` позволяет указать другой адрес приложения. При создании снимков скрипт собирает события `pageerror` и завершает проверку с ошибкой, если они обнаружены. При проверенном запуске список `pageErrors` был пуст.

Manrope подключён из npm-пакета Fontsource и включается в сборку. Карта, иллюстрации и иконки создаются кодом; для этих ресурсов приложение не обращается к внешним CDN или сервисам изображений. Установка npm-зависимостей и браузера для тестов отдельно требует доступа к сети.

## CI и исходный архив

В [GitHub Actions](../.github/workflows/ci.yml) независимы два задания: frontend устанавливает зависимости, собирает приложение и запускает автономные браузерные тесты; backend запускает Maven-тесты на Java 21. Полный браузерный сценарий с API не включён в CI, поскольку backend в задании frontend не запускается.

Для передачи исходников из корня проекта:

```sh
python scripts/package-source.py
```

Python создаёт `../qamqor-source.zip` с исходниками, документацией и скриншотами. Скрипт исключает зависимости, локальные инструменты, Git-историю, базы, `.env`, журналы, отчёты тестов и артефакты сборки. Архив не заменяет историю Git и не выполняет публикацию в GitHub.
