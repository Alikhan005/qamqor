# Qamqor в GitHub и портфолио

[Исходный код на GitHub →](https://github.com/Alikhan005/qamqor)

[Открыть интерактивную демоверсию →](https://alikhan005.github.io/qamqor/)

Работодателю удобно отправить две ссылки: публичное демо для знакомства с продуктом и репозиторий для просмотра кода, тестов и архитектуры. На главной странице README уже объясняет задачу проекта и показывает интерфейс.

## Закрепить проект в профиле

1. Откройте свой профиль GitHub.
2. В блоке **Pinned** или **Popular repositories** выберите **Customize your pins**.
3. Найдите репозиторий **qamqor**, отметьте его и сохраните выбор.

Закреплённый репозиторий помогает посетителю сразу найти проект в вашем профиле. Эти шаги описаны в [официальной инструкции GitHub](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/pinning-items-to-your-profile).

## Описание репозитория

Текст для поля **Description**:

```text
Community help platform for Kazakhstan with an interactive 3D map — Angular, Three.js, Java 21 and Spring Boot.
```

В поле **Website** укажите адрес работающего публичного демо из начала этой страницы.

Темы для **Topics**:

```text
angular java spring-boot threejs typescript kazakhstan volunteering docker portfolio
```

README включает назначение проекта, скриншот, стек, сценарии, команды запуска и ограничения демонстрации. Во вкладке **Actions** можно проверить результаты сборки и тестов конкретного коммита.

## Сохранить и поделиться

- **В браузере:** откройте демо и нажмите `Ctrl+D`, чтобы сохранить его в закладки.
- **В GitHub:** кнопка **Star** сохраняет репозиторий в вашем списке избранного.
- **В резюме:** добавьте название **Qamqor**, одну фразу о пользе проекта и ссылки на демо и исходники.

Пример короткого сообщения работодателю:

> Qamqor — мой проект платформы волонтёрских инициатив в Казахстане. В браузере можно выбрать город на 3D-карте, найти инициативу, сохранить её и попробовать участие. Стек: Angular, Three.js, Java 21, Spring Boot и JPA. В репозитории есть REST API, тесты, Docker и описание архитектуры.

Публичное демо использует вымышленные данные и хранит изменения в браузере посетителя. Серверная реализация на Java находится в `backend/` и запускается по инструкции в [README](../README.md).

## Обновить опубликованный проект

Из папки `qamqor`, после проверки изменений:

```powershell
git status
git add README.md docs frontend backend .github
git diff --cached --stat
git commit -m "Improve Qamqor"
git push
```

Добавляйте только относящиеся к изменению файлы. Зависимости, локальные базы, `.env`, инструменты и результаты сборки исключены через `.gitignore`.
