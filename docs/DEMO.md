# Посмотреть Qamqor за 60 секунд

[Открыть интерактивную демоверсию →](https://alikhan005.github.io/qamqor/)

**Qamqor помогает найти небольшое полезное дело рядом: выбрать город, понять задачу и присоединиться к инициативе.** Проект показывает путь от идеи продукта до Angular-интерфейса, Java API и сохранения данных.

## Сценарий для первого знакомства

| Время | Действие | Что видно |
| --- | --- | --- |
| 0–15 с | Выберите город на карте или в фильтре | 3D-карта Казахстана связана с каталогом; список учитывает выбранный город |
| 15–30 с | Выберите категорию, откройте инициативу | Задача, дата, место, срочность и свободные места собраны в карточке |
| 30–45 с | Добавьте инициативу в избранное и оставьте отклик под вымышленным именем | Изменяются прогресс набора и раздел «Мои отклики» |
| 45–60 с | Обновите страницу, затем переключите язык RU/KZ | Состояние сохраняется, интерфейс доступен на двух языках |

Для более подробного показа создайте инициативу через форму и откройте сайт на телефоне. Можно пройти тот же путь без 3D-карты, используя обычный список и фильтры.

Публичное демо хранит изменения в браузере посетителя; они не публикуются другим пользователям. Инициативы, участники и статистика вымышлены. Java REST API реализован отдельно и доступен при запуске полного стека по [README](../README.md).

## Что показать техническому интервьюеру

- **Состояние интерфейса:** Angular signals, сочетание фильтров, формы, избранное и сохранение после обновления страницы.
- **Графика и доступность:** Three.js, связь карты с каталогом, SVG-резерв без WebGL, клавиатура и мобильная вёрстка.
- **Путь данных:** Angular → HTTP → DTO → сервис Spring Boot → Spring Data JPA → база.
- **Бизнес-правила:** проверка полей, запрет участия в закрытой или заполненной инициативе, обработка повторного отклика и одновременной записи участников.
- **Качество:** 7 интеграционных Java-тестов, 9 автономных браузерных сценариев и дополнительный сценарий с API; команды и условия в [VERIFICATION.md](VERIFICATION.md).
- **Дальнейшее развитие:** авторизация, роли организаторов, модерация и подготовка к работе с реальными данными.

Для показа полного стека запустите backend и `npm run start:api`, создайте вымышленную инициативу, затем покажите ответ `http://localhost:8080/api/requests` или HTTP-запрос во вкладке Network. Так можно увидеть работу серверного хранения, а не только браузерного состояния.

## Описание для резюме

> **Qamqor — платформа волонтёрских инициатив в Казахстане.** Angular 21, TypeScript и интерактивная 3D-карта Three.js; REST API на Java 21 / Spring Boot 3.5.16. Поиск и фильтрация инициатив, создание задач и запись участников, серверная валидация и сохранение через Spring Data JPA. Автономное демо в браузере, интеграционные и браузерные тесты, Docker Compose и GitHub Actions. Проект для портфолио с демонстрационными данными.
